
# 🎮 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a Hangman game in Python to practice strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Select and Display a Hidden Word

#### Description
Choose a word for the round and show the player its unrevealed letters.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list.
- Display one underscore for each letter in the selected word.

### 🛠️ Run the Guessing Round

#### Description
Let the player guess letters until they reveal the word or run out of attempts.

#### Requirements
Completed program should:

- Accept letter guesses and update the displayed progress when a guessed letter appears in the word.
- Track and display the number of incorrect guesses remaining.
- End the game when the word is guessed or no attempts remain.
- Display a win or lose message when the game ends.
